# 🌦️ Weather Report App

A simple and stylish weather forecast application built using **ReactJS** and **Tailwind CSS**, powered by the **OpenWeatherMap API**. Users can enter a city name and instantly view current weather details with a dynamic background.

---

## 🚀 Features

- 🔍 Search for any city's weather
- 🌡️ Displays temperature, condition, humidity, and wind speed
- 🎨 Dynamic background image based on weather conditions
- 📱 Responsive design using Tailwind CSS

---

## 🛠️ Tech Stack

- **ReactJS**
- **Tailwind CSS**
- **Axios** (for API calls)
- **OpenWeatherMap API**


---
